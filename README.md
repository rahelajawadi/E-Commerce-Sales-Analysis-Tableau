# E-Commerce Sales Analysis Dashboard


## Overview

This project analyzes e-commerce sales data to explore sales performance, customer purchasing patterns, and key business trends through interactive Tableau visualizations.

## Highlights

- **Sales Analysis**
  - Examines sales performance across products, categories, and other key dimensions.

- **Trend Analysis**
  - Identifies patterns and trends in e-commerce sales data.

- **Data Visualization**
  - Presents insights through interactive Tableau charts and dashboards.

- **Business Insights**
  - Transforms sales data into meaningful insights to support data-driven decision-making.

**Tableau** · **Data Visualization** · **Business Intelligence** · **E-Commerce Analytics**

- Transformed e-commerce sales data into actionable insights through interactive Tableau visualizations.
